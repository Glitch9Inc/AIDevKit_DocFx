    Class ReflectionAssetDatabase

    Holds the asset database path for reflection-based loading of assets at runtime.

    This class is used to reference the AssetDatabase path without direct dependencies, allowing runtime assemblies to load assets via reflection without requiring UnityEditor define symbols.
